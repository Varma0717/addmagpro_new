## 🚀 QUICK START GUIDE

### Web UI (localhost/admagpro)

**Setup:**
```bash
cd c:\xampp\htdocs\admagpro
composer install
npm install
npm run build
php artisan migrate
```

**Access:**
```
Home: http://localhost/admagpro/home/new
Login: http://localhost/admagpro/login/new
Products: http://localhost/admagpro/products/new
Admin: http://localhost/admagpro/admin/new
```

### Mobile App (Flutter)

**Setup:**
```bash
cd mobile-apps/addmagpro_mobile
flutter pub get
# Update API URL in lib/core/config/app_config.dart
flutter run -d emulator-5554
```

**Build:**
```bash
# Android APK
flutter build apk --release

# iOS
flutter build ios --release
```
